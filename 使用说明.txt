XAIHI · A QUESTION FOR YOU
完整原生终端音乐演出 · 使用说明（纯文本）
================================================

时长约 3 分 32 秒（211.91 秒），24 帧/秒。

本目录是"不含音乐"的终端工程：程序、人物素材、歌词、对白、中文点阵
与预计算音频特征都在，但不含歌曲，也不含成片视频。


一、运行
------------------------------------------------
双击  启动终端.cmd
或在命令行里：
    py -3 player.py
（没有 py 启动器就用  python player.py）

需要：
  · Windows
  · Python 3.10 以上
  · 支持真彩色的终端（推荐 Windows Terminal）
终端窗口推荐 197 列 × 60 行，最低 184 列 × 60 行。
播放器只依赖 Python 标准库，默认静音。


二、带音乐播放
------------------------------------------------
    py -3 player.py --audio "D:\你的音乐.wav"
本工程不含歌曲，需要自备音频文件。


三、控制
------------------------------------------------
    空格          暂停 / 继续
    左右方向键     快退 / 快进 3 秒
    [ ]           切换镜头
    C             切换中文
    M             切换人物周期性起伏
    R             重播
    Q             退出

播放结束后画面停留，按 R 可重播。
M 不关闭镜头推近和程序图形。


四、角色与对白
------------------------------------------------
  · 管理员 ENDMIN
      白色、靠左、稍小的英文像素字，显示输入光标及 TYPING / SENT 状态；
      中文同样为白色。
  · 赛希 XAIHI
      青色、居中的大号英文像素字；中文用浅青色。
  · 未发送草稿 DRAFT
      黄色，并显示删除过程。

每条对白单独显示。画面里的"输入动画"是剧情演出，不会真正发送消息，
也不需要你输入任何对白。

50 条对白为原创同人试写，英文是适应终端排版的简短译写，不是游戏官方原句。
全文见同目录的  对白稿.txt 。


五、画面
------------------------------------------------
  · 前段：掌心构建与世界初始化。
  · 中段：结合歌词绘制点集、圆、正弦、无穷、时间、植物与猫的字符图形。
  · 后段：连接等待、记忆碎片、进程执行、心形与告别。
英文歌词优先保证完整可读，较长的歌词使用更紧凑的像素字体。

人物为静态素材的平移、镜头推近与轻微起伏，
没有宣称真实眨眼、口型或骨骼动画。

关键换景使用约 0.4 秒的数字扫描与展开，旧场景逐渐变暗，
歌词和对白保持原时间轴。


六、音频特征
------------------------------------------------
音频特征已按整首本地音频预先计算为 24 个频段、RMS、波形和连续数据流
（assets/audio_features.json），不是麦克风或实时音频输入。
因此即使静音播放，画面也会按原曲的起伏演出。

替换歌曲时必须重新分析音频并调整歌词时间轴，
否则画面与音乐会对不上。


七、文件结构
------------------------------------------------
    player.py                    播放器（仅标准库）
    启动终端.cmd                  启动脚本（相对路径，任何机器可用）
    使用说明.txt                  本文件
    对白稿.txt                    50 条对白全文
    assets/portraits.json        人物素材清单（角色名 → 源文件）
    assets/*.rgba.z              8 张人物素材（压缩 RGBA）
    assets/lyrics.json           歌词与时间轴
    assets/dialogue.json         50 条对白与时间轴
    assets/dialogue_glyphs.json  中文点阵字形
    assets/shots.json            36 个镜头段落
    assets/audio_features.json   预计算音频特征
    previews/                    关键帧预览图（播放器不读取）


八、其他说明
------------------------------------------------
  · 有声成片单独提供，由同一套终端字符和颜色逐帧绘制，
    不是终端窗口实录。
  · 真实终端的字体和中文点阵显示可能与成片略有差异。
  · 本工程不含歌曲与视频，分发时同样不含，请注意音频版权。
  · 把终端画面渲染成正常成片的做法，见  教程-把终端画面渲染成正常成片.txt 。
